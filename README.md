# Football Bet Analyzer V14

PWA personale per GitHub Pages. Analizza Serie A, Premier League, LaLiga e Ligue 1 usando risultati football-data.org, quote reali manuali o facoltativamente TheRundown, filtro prudente e archivio ROI/CLV.

## Avvio

Apri https://giostacchio.github.io/SERIE-A-BET-ANALYZER/, entra in **Impostazioni**, salva il token football-data.org e premi **Salva e aggiorna**.

I token e l'archivio restano nel browser del dispositivo. Le probabilità sono stime statistiche e non garantiscono vincite.
